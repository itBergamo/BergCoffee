 # BERGCOFFE - Landing Page 

 ![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white)

   BergCoffee é uma Landing Page estática, contruída baseada em HTML Semântico e CSS, ela foi desenvolvida como o primeiro projeto do **Roadmap Trilha Front-End do 0 ao Avançado**, criado e desenvolvido por mim através do ChatGPT, e é baseada no projeto disponibilizado no YouTube pela @rafaballerini em seu canal @RafaellaBallerini (https://youtu.be/Lx_YsoMgP40?si=AHwPJIg2F6GnZfFB). 
 
   Desenvolvi este projeto em duas partes, sendo que na primeira parte o código escrito é acompanhado junto com a aula online disponibilizada e na segunda parte, após eu apagar todo o código, recomeço novamente, mas dessa vez sem acompanhar ao vídeo, revisando e testando o conhecimento adquirido, sendo substituidas algumas parte de design para se tornar um projeto próprio.
